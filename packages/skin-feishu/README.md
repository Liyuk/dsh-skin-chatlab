# @liyuk/dsh-skin-feishu

飞书(Lark)风格聊天皮肤,基于 `@liyuk/dsh-skin-chatlab-core` 基座。

效果:
- 工作区 = 项目组(彩色方块 + 首字母)
- 会话 = 联系人(圆形头像 + 最近回复预览 + 未读红点)
- 聊天气泡化(蓝色气泡 + 已读标记)
- 保留原 DeepSeek 品牌 + 皮肤名徽章

## 安装

```sh
dsh plugin --profile web add @liyuk/dsh-skin-chatlab-core @liyuk/dsh-skin-feishu
```

或装聚合包 `@liyuk/dsh-skin-chatlab`(自动带上 core + 本包)。
